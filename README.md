# PinoySoftHub

Free software, games & apps — a static catalog site with **1037 posts**.

## Contents
- `index.html` — homepage with live search, category filters, and pagination
- `games/` — 1036 individual software/game pages

## Features
- Dark theme
- Real-time search filter
- Category filter buttons
- "Will It Run On My PC?" system-requirements checker on every page

## Build (optional)
The site is generated from scraped data; only the static output is committed here.
